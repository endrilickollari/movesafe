# movesafe v0.1.0 benchmark

Run on 10 August 2026 with the repository benchmark harness and Node.js 26.4.0. Each counted repository completed this gate:

1. Install the repository's dependencies with its detected package manager.
2. Build its TypeScript import graph.
3. Select and apply available file, directory, and cross-package moves.
4. Run `movesafe check` after the moves.
5. Run TypeScript before and after, accepting existing errors only when the final count does not increase.

Safely refused plans are allowed. Incorrect edits, a dirty checker result, new TypeScript errors, incomplete TypeScript execution, or an incomplete benchmark run are not counted.

These are harness or repository-environment limitations, not successful Movesafe validations. They remain visible so the headline cannot overstate the evidence.

## Reproduce

```bash
pnpm --filter @movesafe/core build
cd packages/benchmark
node --max-old-space-size=8192 --import tsx src/run-benchmark.ts \
  --only zustand --output results/zustand.json
```

Run each configured repository in a separate process to release its TypeScript program and import graph before the next target. Replace `zustand` with another name from `src/repos.ts`; `--output` retains the JSON result.
