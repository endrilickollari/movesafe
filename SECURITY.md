# Security Policy

## Supported versions

Movesafe currently provides security fixes for the latest `0.1.x` release line.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |
| < 0.1   | No        |

## Report a vulnerability

Do not open a public issue or discussion for a suspected vulnerability.

Use GitHub's
[private vulnerability reporting](https://github.com/endrilickollari/movesafe/security/advisories/new)
to send the maintainer a confidential report. Include:

- the affected package, version, and interface;
- the impact and conditions required to reproduce it;
- a minimal reproduction or proof of concept when safe to share;
- any suggested mitigation;
- whether the issue has been disclosed elsewhere.

Remove credentials, tokens, private source code, and unrelated personal information from the
report.

The maintainer will acknowledge the report as soon as practical, investigate it privately, and
coordinate a fix and disclosure when the impact is confirmed. Please allow reasonable time for a
patch before publishing details.

Use the public bug-report form for reliability problems that do not create a confidentiality,
integrity, or availability risk.
